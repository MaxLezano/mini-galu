# Fuentes

Archivos variables (solo latín: alcanza para el español) de Google Fonts, bajados de Fontsource 5.3.0. Se sirven
desde el proyecto (`next/font/local` en `app/layout.tsx`) para no depender de Google al compilar ni en el CI.

| Fuente   | Archivo                                   | Ejes                         | Licencia          |
| -------- | ----------------------------------------- | ---------------------------- | ----------------- |
| Fraunces | `fraunces-latin-full-{normal,italic}.woff2` | wght, opsz, SOFT, WONK       | `OFL-fraunces.txt` |
| Manrope  | `manrope-latin-wght-normal.woff2`         | wght 200–800                 | `OFL-manrope.txt`  |
| Caveat   | `caveat-latin-wght-normal.woff2`          | wght 400–700                 | `OFL-caveat.txt`   |

Las tres son SIL Open Font License 1.1: se pueden usar y distribuir con la web acompañadas de su licencia.
